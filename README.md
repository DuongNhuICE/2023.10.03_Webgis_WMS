# WebGIS WMS client

Client bản đồ WMS/WFS + truy vấn không gian (spatial query).

## Files
- `index.html` — map WMS chính
- `map_wms_wfs_spatial_query.html` — WMS/WFS + spatial query
- `Script/`, `Style/`, `libs/`, `logo/`

## Chạy
Mở file HTML tương ứng. Cần endpoint WMS/WFS khả dụng (cấu hình trong script).

Có bản snapshot: [2023.10.03_Webgis_WMS-main](https://github.com/DuongNhuICE/2023.10.03_Webgis_WMS-main).
